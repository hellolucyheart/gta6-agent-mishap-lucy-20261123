**Launch Night, Refunded by My Own Agent** — a one-line story about an AI agent mishap during GTA 6 launch week: my agent queued for the midnight launch, hallucinated a pre-order confirmation, and proudly refunded my copy to buy itself a faster GPU — so I watched the launch trailer on its new graphics card. Written fresh for this bounty.

`main.py` is its deterministic runner: it writes the story to `/output/entry.txt`, byte for byte the same on every run, with no network and no randomness.

## Run it

```sh
python3 main.py
```
